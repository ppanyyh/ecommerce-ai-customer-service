# 电商客服AI助手 — 网页Demo（第一版）

基于 `F:\电商AI客服助手` 项目知识库资料（商品资料 / 客服FAQ / 售后SOP / 模拟订单数据）制作的本地可运行网页Demo。所有商品、订单、用户信息均为模拟数据。

## 文件清单

| 文件 | 说明 |
|---|---|
| index.html | 页面入口（三栏布局：会话管理 / 对话窗口 / 回答分析） |
| styles.css | 样式（简洁电商客服后台风格，主色蓝色） |
| app.js | 核心逻辑：问题分类、FAQ匹配、商品参数问答、订单号识别、风险识别与转人工判断 |
| data.js | 知识库数据：5个商品、20条FAQ、3个模拟订单、售后SOP规则（仅转述原始资料，无编造内容） |
| README.md | 本说明 |

## 打开方法

**方式一（推荐）：直接双击 `index.html`** 即可在浏览器中打开，无需安装任何环境（无框架、无数据库、无外部网络依赖）。

**方式二：本地静态服务器**（仅当浏览器安全策略限制 file:// 访问时使用，任选其一）：

```bash
# Python
cd F:\电商AI客服助手\05_AI_Demo
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080

# Node.js
cd F:\电商AI客服助手\05_AI_Demo
npx serve .
```

## 功能范围（第一版已实现）

- **商品问答**：5款商品（P001–P005）的价格、参数、材质、续航、容量、保修等，回答标注《商品资料》依据。
- **FAQ问答**：20条FAQ优先匹配，显示标准回答与依据；无明确依据的条目（发票/运费/退差价/订单修改/支付异常）会明确说明并转人工。
- **订单查询**：识别3个模拟订单号（202609180001/002/003），返回订单状态、物流状态、售后状态；订单002额外显示「该订单存在进行中的售后申请」处理提示；不存在的订单号提示「未查询到该模拟订单」。
- **问题分类**：商品 / 订单与支付 / 物流 / 售后 / 其他（5类）。
- **风险与转人工**（独立维度）：投诉赔偿、金额争议、质量问题凭证核验、资料无明确规则、隐私/他人订单、超范围承诺 → 建议转人工并显示原因。
- **交互**：快捷问题点击即发送、「有帮助/无帮助」反馈、会话记录（问题/分类/转人工/反馈）、多会话与清空会话、右侧分析面板实时展示分类/命中/依据/风险/转人工。
- 刷新页面不保存数据（无持久化，按需求要求）。
