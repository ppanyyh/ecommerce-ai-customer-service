# 源码与发布说明

## 原始源码位置

`F:\电商AI客服助手\09_V3_Vector_RAG`

本作品集目录没有复制 1.2GB 的 `.venv`、本地向量库和模型缓存，也没有复制全部历史调试产物。这样便于投递和备份，并降低误传密钥、缓存与临时数据的风险。

## 本地运行

```powershell
cd F:\电商AI客服助手\09_V3_Vector_RAG
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --app-dir backend
```

浏览器访问：

- 前端：`http://127.0.0.1:8000/`
- 健康检查：`http://127.0.0.1:8000/api/health`
- 就绪检查：`http://127.0.0.1:8000/api/ready`

停止服务：在启动终端按 `Ctrl+C`。

## 创建公开代码仓库前

1. 从原项目复制源码到新的发布目录。
2. 排除 `.venv`、`.env`、`__pycache__`、Chroma 数据库、模型缓存、错误日志和临时文件。
3. 检查所有 JSON、Markdown 和测试数据只包含模拟数据。
4. 保留 `.env.example`，不要保留真实 Token。
5. 在仓库首页标明 V3.2.2/V3.2.3 的评测边界以及 `production_ready=false`。
6. 从干净环境按 README 安装依赖并至少完成一次启动检查。

## 关于 Hugging Face 警告

未设置 `HF_TOKEN` 时可能显示未认证请求警告。这不是业务报错；模型已缓存且服务就绪时可以忽略。若配置 Token，只放在环境变量或本地 `.env` 中，禁止提交到仓库。
